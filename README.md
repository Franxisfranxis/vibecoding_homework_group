# 奶娃的草原大冒险

**在线试玩：** https://franxisfranxis.github.io/vibecoding_homework_group/

一个以队友提供的 `奶娃.jpg` 为灵感制作的浏览器 3D 闯关游戏。玩家操控几何体奶娃，用子弹清掉草原上 23 只捣蛋怪，再打碎守在出口门前的魔王。

## 运行

**双击 `start.bat`** 即可（自动起服务器并用默认浏览器打开）。

或手动在 `world/` 目录执行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8000/`。由于使用 ES module，不能直接双击 `index.html`。已使用 Three.js 0.180.0，建议使用最新版 Chrome 或 Edge 桌面浏览器。

## 操作

- WASD 或方向键：移动奶娃
- 空格：发射子弹，方向 = 奶娃当前朝向（移动时会自动朝向锁定的目标），**按住可连射**（冷却 0.26 秒）
- Q：消耗 1 次治疗次数，回复 1 滴血；每击杀 1 只绿色回血怪获得 1 次，本局全程有效、无冷却，满血时不消耗（生命上限仍为 5）
- E：进入 Boss 战后解锁激光，本局共 3 次，每次使用后冷却 15 秒；自动射向 Boss，使用与普攻相同的距离衰减公式，伤害为同距离普攻的 4 倍，护盾期间只造成 25% 伤害；Boss 在空中时不可使用且不消耗次数
- Esc：返回菜单
- 音效按钮：开启/关闭音效
- Shift：无敌冲刺，沿移动方向冲刺 3 格（站定不动时按面朝方向）；冲刺期间免受伤害
- R：强化普攻，使用后 6 秒内每次普攻改为三颗扇形子弹、伤害翻倍；冷却 20 秒

> **移动攻击**：跑动时奶娃会自动锁定**屏幕内**最近的存活目标（含 Boss），身体转向它、脚步仍按 WASD 走，所以可以侧身跑、倒着跑边躲边打。锁定目标脚下有一对旋转的青色弧线、头顶有一个倒三角。镜头里一个目标都没有时，才朝移动方向。
>
> 站定不动时保持原样：自动转向**最近的**存活怪物（不限屏幕），方便远程点射。

## 怪物

| 类型 | 颜色 | 血量 | 行为 |
| --- | --- | --- | --- |
| 普通捣蛋怪 | 粉紫 | 3 | 靠近后贴身撞击，-1 |
| 射手怪 | 橙红（金角 + 炮口） | 10 | 距离 <10 时每 1 秒射一颗**红色**子弹，-1；太近会后撤 |
| 激光怪 | 亮紫（青角 + 青色核心） | 12 | 距离 <12 时蓄力 1.2 秒，射出**红色**激光柱，-2 |
| 弹幕怪 | 亮蓝（洋红尖刺 + 洋红核心） | 18 | 距离 <14 时蓄力 0.55 秒，扇形撒出 **10 颗洋红色**弹幕，单颗 -1 |
| 光圈怪 | 亮黄（头顶双金环） | 14 | 距离 <13 时，在**奶娃脚下**投下金色光圈，1 秒后爆发，-2。**全场 6 只** |
| 回血怪 | 薄荷绿（头顶白十字） | 8 | **完全不动**。给半径 8.5 内的其他怪每秒回 0.6 点血，回血时拉出绿色光束 |

## 行动状态机（很重要的手感设定）

每只杂兵有三个状态，循环往复：

```
idle（不动）──玩家进入警戒范围──> chase（追 3 秒）
   ↑                                      │
   │                              3 秒到，放弃
   └──踏进回血怪光圈 / 休息 2.5 秒──────── retreat（0.9 速度慢慢走）
```

- **idle**：原地站着不动（也会停止攻击）。每类怪的警戒范围不同：普通 6 / 射手 10 / 激光 12 / 弹幕 14 / 光圈 13。不走进去它们就不会理你。
- **chase**：追 3 秒，各类型按自己的站位习惯走位（射手 7 格、激光 9 格、弹幕 11 格、光圈 10 格），期间正常开火。
- **retreat**：计时归零后放弃追击，**不再攻击**，以 0.9 的速度慢慢走向最近的回血怪；**一踏进治疗光圈（8.5 半径内）就停下**，歇 2.5 秒，之后玩家还在警戒范围内才会再次开追。
- 回血怪全被清掉后，撤退目标消失，怪物就地停下，只会在被靠近时做一次 3 秒的短追击。

> 所以正确打法是：在它追你的 3 秒里输出，它转身走的时候追着打背——那是它最脆弱、也最好打的 3~9 秒。

## BOSS：门口的魔王

位置 `(0, -12.6)`，血量 **50**，体型是普通怪的 2 倍多。

**休眠期**：开场时它是一尊深灰色石像，罩着淡蓝护盾球——**不吃伤害、不移动、不攻击**。此时子弹打上去会被弹开（有闷响 + 护盾波纹），这是刻意的提示，不是你打偏了。

**苏醒**：场上 23 只杂兵全部清空的那一刻，护盾碎裂、身体转为暗红、发光并发出低鸣，HUD 从 `👾 23 / 23` 切换为 `👹 BOSS 50 / 50`。

**技能循环**：每放完一招，随机抽下一招（不会连续重复同一招）。

| 技能 | 表现 | 应对 |
| --- | --- | --- |
| 三段弹幕 | 连续撒 3 波，三波数量不同（约 7~16 颗），扇形 90° | 侧向移动穿过弹幕缝隙 |
| 激光走廊 | 同时生成 **6 道**平行激光，横竖随机，把场地切成几条走廊 | 站到两条激光中间的空档里 |
| 光圈阵 | **8 个**光圈随机撒在奶娃周围 9.5 半径内，1.2 秒后同时爆发，各 -2 | 朝没被光圈覆盖的方向跑出去 |
| 巨大追踪弹 | 一颗大红球追踪 3 秒，命中 -3 | 绕圈甩它；**3 秒后熄火变橙色，可被打掉，需要 3 发** |

**二阶段（生命降至 25 或以下）**：立即停止第一阶段技能，起跳到空中，不能被普攻命中或自动选中。起跳时锁定玩家的位置，地面显示半径 **3.15** 的落点圆圈；躲避时间 **1.5 秒**。落地瞬间圆内玩家扣 **3 血**，伴随闪电特效和雷声音效。每次落地至下一次起跳间隔 **3.5 秒**。

**有限护盾**：二阶段初始护盾值 **35**，落地期间生效；普攻和激光均按距离衰减后的原始伤害扣除护盾值，同时对本体造成 **25%** 伤害。破盾这一击仍按命中前的护盾状态减伤，后续攻击恢复原伤害。护盾耗尽后永久移除，不会在下次落地时补回。HUD 显示剩余护盾值。

**永久分裂光球**：仅首次落地时，在玩家周围半径 **7.5** 处以 **90°** 间隔生成 **4 颗光球**，向释放时锁定的玩家位置合围（边缘生成点限制在地图内）。此后每次砸下瞬间，场上每颗光球向相隔 90° 的四方向分裂为 **4 颗**（替代原球，净增 3），总数最多 **256**；空间不足以完成一次四分裂时，该球保持原状。若所有球都命中消失，不额外重新发射。初始速度为玩家移速 **80%**（速度 **4**），之后每次落地为**所有存活光球**增加玩家移速 **10%**（速度增加 **0.5**），上限 **150%**（速度 **7.5**，第 8 次落地达到）；达到数量上限不影响加速，达到速度上限也不影响分裂。所有球沿直线移动，触碰地图边界后反转整个速度向量、沿原直线往返，不超时消散，仅接触玩家时消失（每颗 **1 血**，保留原无敌帧）。重开、返回菜单或击败 Boss 时清理光球。

## 数值

- 玩家生命：**5 点**（撞击 -1，激光 -2，弹幕单颗 -1，光圈 -2，BOSS 追踪弹 -3）
- **每清掉 3 只怪回复 1 点血**（3/6/9/12/15/18/21 只时触发，上限 5）
- 玩家体型：`PLAYER_SCALE = 0.75`，碰撞半径同步缩小（被子弹命中判定 0.45，被撞击判定 0.85）
- 受伤后 1.5 秒无敌，角色闪烁；**无敌帧内不再吃第二次伤害**（否则密集弹幕会瞬间秒杀）
- 玩家子弹：青蓝色，基础伤害 1.0，冷却 0.26 秒
- 怪物头顶有血条，随血量由绿 → 黄 → 红渐变，始终朝向相机
- 被击中时怪物短暂闪白

### 子弹的距离衰减

**只有玩家自己的子弹**会随飞行距离掉伤害，敌人子弹固定 1 点。伤害与怪物血量都按浮点结算。

| 飞行距离 | 伤害 |
| --- | --- |
| ≤ 3.5 | **1.00**（满伤） |
| 8 | 0.84 |
| 12 | 0.69 |
| 16 | 0.55 |
| ≥ 20 | **0.40**（下限，不再继续掉） |

曲线是 `FALLOFF = { near:3.5, far:20, min:.4 }` 之间的线性插值（`falloffAt()`）。

三种可视化让衰减可见：

1. 子弹飞行中由**青蓝渐变为暗蓝**，能量条同时变短变细
2. 命中时怪物头顶飘出**实际伤害数字**（1.0 / 0.8 / 0.7 / 0.4），满伤青白、中距离黄、远距离橙红
3. 血条按浮点比例缩短

实战影响：3 血普通怪贴脸 3 发、8 格 4 发、18 格 7 发。所以别再站在场地另一头点射，**靠近了打效率高得多**。BOSS 的追踪弹和本体同样吃这个衰减。

## Demo 模式

在开始界面点击 **Watch Demo**，观看约 **76 秒**的带章节字幕实时教学演示（不是外部视频文件）：

- **Boss 一阶段与玩家技能，约 23 秒**：休眠护盾挡子弹、三段弹幕、六道激光走廊、光圈阵、追踪巨球熄火后可击落，以及 E 激光的实际伤害、次数消耗与 15 秒冷却。
- **Boss 二阶段，32 秒**：镜头明确快进至半血，实际展示 1.5 秒空中不可选中、落地闪电、躲避跳砸、35 点有限护盾减伤与破盾后全伤害、光球合围、落地分裂加速和边界反向往返；自动普攻与 E 遵守真实伤害及冷却。

镜头切换时仅为教学调整怪物位置、隐藏无关怪物并清理上一镜头弹道，不改变正式游戏数值。演示中敌人攻击不扣玩家血，绿怪章节预设为 3 血以展示 Q 回复效果。点击“退出演示”或 Esc 可提前返回菜单，重新开始游戏会恢复正常关卡与全部初始状态。

## 游戏目标

先清掉 23 只捣蛋怪（其中 6 只光圈怪），再击碎门口的魔王。生命值耗尽则失败。

## 已知限制

- 角色和怪物采用 Three.js 基础几何体，未进行角色骨骼动画。
- 音效由 Web Audio API 实时生成，无外部音频文件。
- 子弹碰撞采用分步扫描（子步进），低帧率下不会穿透。
- 激光命中判定为二维（忽略高度）。
- BOSS 第一阶段本体不会移动，只转身朝向玩家；第二阶段会跳向起跳时锁定的玩家位置。
- Three.js 运行文件和 MIT 许可证包含在 `vendor/` 中，运行时无需安装依赖或连接网络。
- 目前只支持桌面键盘鼠标：手机或平板能进菜单，但没有触屏操作，无法移动和射击。
- 音效只能整体开关，没有音量调节；且需要先点击页面才启用。
